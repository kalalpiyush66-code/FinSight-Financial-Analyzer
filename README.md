Finsight Financial Analysis Made Simple
## About

FinSight Financial Analyzer is a financial analysis application built using Python and Streamlit. It helps users perform financial calculations through a simple, interactive interface.

## Features

- Financial calculations and analysis
- Constant Growth Rate analysis
- Discounted Cash Flow (DCF) valuation
- Interactive and user-friendly interface

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- NumPy Financial

## How to Run

1. Clone this repository:
   `git clone <your-github-repository-url>`

2. Navigate to the project folder:
   `cd <your-project-folder>`

3. Install the required libraries:
   `pip install -r requirements.txt`

4. Run the application:
   `streamlit run main.py`
